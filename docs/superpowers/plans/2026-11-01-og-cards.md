# OG Cards Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serve live 1200x630 preview cards and per-link meta tags for player profiles, leaderboards and team invites.

**Architecture:** A new `apps/api/src/og/` module renders JSX cards with one shared Takumi `Renderer` and exposes image routes under `/api/og/`. The API also serves `/stats/` (when filtered) and `/t/:code` as the built HTML with tags injected; Caddy routes those paths to it. The client shows `/t/<code>` as the share link and converts it to the existing `/#<code>` on load.

> **Implemented on `og-cards`, based on PR #1 (`bun-migration`).** It differs from the steps below: routes use Elysia; team code lives in `game/teamMenu/`; filters validate through the zod schemas, because `statsFilters.ts` exists only on PR #3; takumi is pinned to 2.18.1 for the repo's 7-day release-age rule; `@takumi-rs/core` is imported directly and shipped beside the bundle.

**Tech Stack:** Bun, Elysia, takumi-js 2.18.1 (native backend), React JSX types for cards only, Caddy, Docker.

**Spec:** `docs/superpowers/specs/2026-11-01-og-cards-design.md`. Visual source: `/home/dev/code/survev-og-spike/gen9.tsx` and `out9/`.

## Global Constraints

- Cards are exactly 1200x630 PNG. Port layout values from `gen9.tsx`; do not redesign.
- Fade is the `V == "c"` branch of `side()`: blur `blur(34px) brightness(.72) saturate(1.8)`.
- Accent `#ffdb00`. Font Phantom Guardians with bundled Noto fallbacks. No runtime font downloads.
- Import filter values from `packages/shared/types/statsFilters.ts`, and map data from `MapDefs` and `MapId`; never re-type them.
- No `as` casts on request strings: look values up in their source lists.
- Settings are env vars in `apps/api/src/env.ts`, not config files.
- `@survev/logger` and other client-safe packages must not gain Node imports from this work.

## Review Focus

1. A username containing `"`, `<` or `</title>` in a meta tag must be escaped, never break out of the attribute. Test in Task 4.
2. A 16-character wide name (`WWWWWWWWWWWWWWWW`) must stay inside its column on every card. Test in Task 2.
3. Non-Latin names (Japanese, Cyrillic, Korean) must render real glyphs, not boxes. Test in Task 1.
4. A team code that is invalid or for a dead room must return a generic card with status 200, since crawlers cache failures. Test in Task 3.
5. `/t/<code>` loaded by a real browser must still join the room, and relative assets must load. Test in Task 5.
